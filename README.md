# 犬の食と健康 学習ノート

お店で犬の食の相談（フード、栄養、サプリ、涙やけ、腎臓病、食べない、歩けない など）を受けたときに、誠実に対応できるよう知識を身につけるための学習 PWA。

- **よむ**：13章50節。各テーマに「根拠の強さ（A〜D）」「獣医さんへつなぐサイン」「言い換えの練習（NG/OK）」
- **カード**：143枚。間隔反復（1→3→7→14→30→60日）
- **テスト**：4択72問。全範囲ランダム／苦手から／章ごと。答えるとすぐ解説
- **相談**：お店で受けそうな相談10ケース。聞く→見極める→伝える の3ステップと返答例
- **道具**：RER/DER・乾物量換算・卵殻カルシウムの計算機、BCS早見表

Vanilla JS（ESM）、ビルドなし・外部依存ゼロ。記録は端末の localStorage。

## 開発

```bash
python3 -m http.server 8772
```

```bash
npm test
```

- 教材は `js/data/part1〜3.js`（章）と `cases.js`（相談）。書式は `js/lib/markup.js` の先頭コメント
- 問題の選択肢は `c[0]` が正解（表示時に並べ替え）
- カード・問題のIDは並び順から振るので、項目を足すときは各章の末尾に
- コードや教材を変えたら `sw.js` の `CACHE` の番号を上げる
